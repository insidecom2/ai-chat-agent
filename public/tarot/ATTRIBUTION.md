# Rider–Waite–Smith Tarot images

The 78 image files in this directory are the Rider–Waite–Smith tarot deck, sourced from [mixvlad/TarotCards](https://github.com/mixvlad/TarotCards/tree/main/tarot/rider-waite/720px).

The source repository identifies this deck as sourced from Wikimedia Commons and released to the public domain. Original illustrations: Pamela Colman Smith, under the direction of Arthur Edward Waite (1909).
